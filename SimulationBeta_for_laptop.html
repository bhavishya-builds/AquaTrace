HOW LEAK DETECTION WORKS
1. Sensors: Measures flow (L/min) and dynamic static pressure (bar).
2. Calibration: Gathers sample baseline distributions during nominal state.
3. Filtering: Rolling window statistics remove transient spikes & noise.
4. Adaptive Thresholds: Triggers anomaly tags using statistical limits ($\mu \pm k\cdot\sigma$).
5. Spatial Correlation: Compares neighboring spatial telemetry gradient profiles.
6. Localization: Pinpoints high-discontinuity pipeline boundaries dynamically.
